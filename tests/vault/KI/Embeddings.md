# Embeddings

Ein Embedding ist eine Liste von Zahlen, die die Bedeutung eines Textes beschreibt. Für deutsche Notizen eignet sich das mehrsprachige Modell `bge-m3`, das lokal über Ollama läuft.

## Ähnlichkeit
Die Kosinus-Ähnlichkeit misst, wie ähnlich zwei Vektoren ausgerichtet sind.
